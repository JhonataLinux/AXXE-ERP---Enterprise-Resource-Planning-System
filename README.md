# AXXE ERP - Enterprise Resource Planning System

## Sobre o Projeto

AXXE ERP é um sistema de gestão empresarial desenvolvido em Python para automatizar processos operacionais, financeiros e administrativos.

O sistema foi projetado para atender empresas que necessitam de controle integrado de estoque, financeiro, vendas e auditoria, oferecendo uma plataforma centralizada para gestão do negócio.

> Por questões de confidencialidade e propriedade intelectual, o código-fonte não está disponível publicamente.

---

## Principais Módulos

* Gestão de Estoque
* Financeiro
* Contas a Pagar
* Contas a Receber
* Pedidos
* Orçamentos
* Auditoria
* PDV (Ponto de Venda)
* Relatórios PDF
* Controle de Usuários e Permissões

---

## Tecnologias Utilizadas

* Python
* Flask
* SQLite
* Jinja2
* Bootstrap
* FPDF
* OpenPyXL

---

## Funcionalidades

### Financeiro

* Controle de contas a pagar
* Controle de contas a receber
* Liquidação de títulos
* Controle de vencimentos
* Relatórios financeiros

### Estoque

* Entrada de produtos
* Reserva automática de materiais
* Baixa de estoque
* Ajustes de inventário

### Segurança

* Controle de acesso por perfil
* Autenticação de usuários
* Auditoria de operações

### Relatórios

* Relatórios PDF
* Exportação de informações
* Indicadores gerenciais
